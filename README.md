# 三国逐鹿（暂定名）

三国题材卡牌构筑肉鸽，玩法参考《小丑牌》(Balatro) 核心循环。求职个人项目。

## 怎么运行

直接用浏览器打开 `deck.html` 就能玩，不需要安装任何东西。
（后续会部署到 GitHub Pages：点链接即玩；再打包成 .exe 可下载版。）

## 当前进度（原型）

- ✅ 战力计算器（兵力 × 士气 的概念演示）— `index.html`
- ✅ 52 张牌生成、洗牌、发牌
- ✅ 手牌排序（按点数/按花色，排序方式持久化）
- ✅ 选牌出牌、10 种牌型识别、兵力 × 士气战力结算、第一关过关判定

## 功能地图（`deck.html` 每块代码是干嘛的）

| 代码块 | 作用 |
|---|---|
| 调参区（文件最上方） | 想调难度就只改这里：目标战力、出牌次数、弃牌次数、牌型数值表 |
| 造牌 / 洗牌 / 补牌 | 生成 52 张牌、打乱顺序、摸牌把手牌补到 8 张 |
| 点牌 / 出牌 / 弃牌 | 玩家操作：选牌、打出去结算、换牌 |
| 识别牌型 | 判断你打出的牌是什么（顺子 / 同花 / 四条…，10 种） |
| 结算战力 | 兵力 × 士气 = 战力，累计达标即过关 |
| 显示 | 把当前状态画到网页上（手牌、进度条、结果区） |

## 设计文档

设计思路、机制决策（羁绊系统、功勋系统）、数值原则都在 `三国逐鹿-设计稿-v0.2.md`。

## 核心设计（一句话）

玩家在 20-40 分钟一局里，通过招兵买马和凑羁绊，把战力从几十滚到几百万；
数字爆炸的爽感 + 每局不同的构筑路线 = 再来一局。
